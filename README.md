# Python Day 105 - Sort a List

This program sorts the numbers in a list in ascending order using the `sort()` method.

## Example

Original list:

```text
[40, 10, 30, 50, 20]
```

Sorted list:

```text
[10, 20, 30, 40, 50]
```

## Concepts Used

* List
* `sort()` method
* `print()`
* Ascending order

## How It Works

1. A list of numbers is created.
2. The original list is displayed.
3. The `sort()` method is used to arrange the numbers.
4. The sorted list is displayed.

## Python Code

```python
numbers = [40, 10, 30, 50, 20]

print("Original list:", numbers)

numbers.sort()

print("Sorted list:", numbers)
```

## Output

```text
Original list: [40, 10, 30, 50, 20]
Sorted list: [10, 20, 30, 40, 50]
```

## Goal

The goal of this project is to understand how to sort elements of a list using the `sort()` method in Python.
